# فیت‌یار | FitYar

نسخه اولیه وب‌اپلیکیشن ورزشی فارسی، راست‌چین و موبایل‌محور. پروژه بدون وابستگی به CDN یا فونت خارجی اجرا می‌شود.

## اجرا
- سریع‌ترین پیش‌نمایش: فایل `FitYar-Standalone.html` (در صورت نیاز به قابلیت PWA، روش بعدی را استفاده کنید).
- برای PWA و Service Worker، پوشه پروژه را با یک وب‌سرور محلی یا هاست HTTPS باز کنید؛ باز کردن مستقیم `index.html` با `file://` امکان نصب PWA و Service Worker را فعال نمی‌کند.
- برای اجرای محلی با Python: داخل پوشه پروژه دستور `python -m http.server 8080` و سپس باز کردن `http://localhost:8080`.

## انتشار روی GitHub Pages
1. یک مخزن جدید GitHub بسازید.
2. تمام محتویات این پوشه را در ریشه مخزن بارگذاری کنید.
3. در Settings → Pages، گزینه Deploy from a branch را انتخاب کنید و شاخه `main` و پوشه `/ (root)` را ذخیره کنید.
4. بعد از انتشار، آدرس HTTPS سایت را با گوشی باز کنید؛ در مرورگرهای پشتیبانی‌شده از منوی مرورگر گزینه نصب/افزودن به صفحه اصلی را انتخاب کنید.

## قابلیت‌های نسخه گسترش‌یافته
- کاتالوگ شروع شامل حدود ۱۲۶ حرکت رایج تمرین باشگاه و خانه (فهرست قابل توسعه، نه ادعای پوشش تک‌تک حرکات جهان)
- افزودن حرکت شخصی با نام دلخواه، عضله، تجهیزات، ست، تکرار/زمان، استراحت و یادداشت
- حرکت‌های شخصی در کتابخانه، برنامه‌ها و جلسات قابل استفاده هستند و در پشتیبان JSON ذخیره می‌شوند
- نمایش خلاصه آخرین اجرای حرکت هنگام تمرین و پیش‌پر کردن وزنه/تکرار از آخرین جلسه برای ثبت سریع‌تر؛ مقادیر قابل ویرایش‌اند
- صفحه پیشرفت، سابقه هر حرکت و مقایسه وزنه ثبت‌شده با جلسه قبل (در صورت وجود داده قابل مقایسه)
- فیلترهای هم‌زمان جست‌وجو، عضله و تجهیزات

## منابع پیشنهادی برای بررسی و توسعه کتابخانه حرکات
- ACE Fitness Exercise Library: https://www.acefitness.org/resources/everyone/exercise-library/
- MuscleWiki Exercise Library: https://musclewiki.com/exercises
- NHS strength and flexibility guidance: https://www.nhs.uk/live-well/exercise/how-to-improve-strength-flexibility/
این منابع برای دسته‌بندی و بررسی حرکت‌ها استفاده می‌شوند؛ محتوای تصویری یا متن دارای حق نشر آن‌ها کپی نشده است. کاتالوگ فعلی همه واریانت‌ها را پوشش نمی‌دهد و برای حرکت‌های فاقد راهنمای اختصاصی، خود برنامه این محدودیت را نمایش می‌دهد.

## محدودیت‌ها
- اطلاعات در `localStorage` همان مرورگر و دستگاه ذخیره می‌شود؛ حساب کاربری، همگام‌سازی ابری و چنددستگاهی وجود ندارد.
- اعداد تغذیه‌ای را کاربر وارد می‌کند؛ برنامه بانک غذایی یا تشخیص خودکار خوراکی ندارد.
- محتوای راهنمای حرکت، راهنمای آموزشی عمومی است و جایگزین مربی واجد صلاحیت یا توصیه پزشکی نیست.
- PWA و Service Worker برای نصب و کارکرد آفلاین به HTTPS یا localhost نیاز دارند. فایل مستقل HTML برای پیش‌نمایش سریع است و Service Worker ندارد.
- این بسته APK کامپایل‌شده نیست.

## ساخت APK با Android Studio و Java (طرح پیشنهادی WebView)
1. Android Studio را نصب کنید و یک پروژه جدید با قالب **Empty Views Activity** و زبان **Java** بسازید.
2. پوشه `fityar` را در `app/src/main/assets/` کپی کنید؛ ساختار باید شامل `assets`، `css`، `js`، `index.html` و فایل manifest باشد.
3. در Activity از `WebView` استفاده کنید و JavaScript و DOM Storage را فعال کنید؛ آدرس `file:///android_asset/fityar/index.html` را بارگذاری کنید. برای مثال:

```java
WebView webView = findViewById(R.id.webView);
WebSettings settings = webView.getSettings();
settings.setJavaScriptEnabled(true);
settings.setDomStorageEnabled(true);
webView.setWebViewClient(new WebViewClient());
webView.loadUrl("file:///android_asset/fityar/index.html");
```

4. در layout یک WebView با شناسه `webView` قرار دهید و Activity را تنظیم کنید. برای `WebViewClient` این import لازم است: `android.webkit.WebViewClient`؛ برای `WebSettings` و `WebView` نیز importهای متناظر را اضافه کنید.
5. چون مسیر `file://` معمولاً Service Worker را فعال نمی‌کند، ذخیره محلی همچنان کار می‌کند ولی برای PWA آفلاین بهتر است نسخه HTTPS میزبانی‌شده را در WebView باز کنید یا روش asset loader رسمی AndroidX WebKit را به کار ببرید.
6. برای ساخت خروجی، از Build → Build APK(s) استفاده کنید. امضای نسخه انتشار و آزمایش روی دستگاه واقعی جداگانه لازم است.

## تست انجام‌شده در این محیط
- بررسی نحوی JavaScript با `node --check` برای فایل‌های JS.
- بررسی موجود بودن فایل‌های اصلی و ارجاع‌های پروژه.
- `node --check` برای فایل‌های جاوااسکریپت پس از تغییرات دوباره اجرا شد و خطای نحوی گزارش نشد.
- اجرای کامل تعاملی مرورگر، نصب PWA، ذخیره‌سازی در چند مرورگر و ساخت APK در این محیط تأیید نشده‌اند؛ ادعای تست کامل مطرح نمی‌شود.


## به‌روزرسانی کتابخانه و پروفایل (اکتبر ۲۰۲۶)

- پروفایل شامل نام نمایشی، سن اختیاری، قد و وزن اختیاری، سطح و سابقه تمرین، هدف، محل تمرین (خانه/باشگاه/ترکیبی)، مدت جلسه، روزهای آزاد، تجهیزات و محدودیت‌های اختیاری است.
- نام ثبت‌شده در داشبورد و فهرست کاربر نمایش داده می‌شود. واحد وزنه در رابط کاربری کیلوگرم است.
- کتابخانه با نسخه‌های متعدد و متداول حرکت گسترش یافته است؛ هیچ فهرستی را نمی‌توان «تمام حرکات موجود در جهان» دانست. کاربران می‌توانند حرکت جاافتاده را با نام دلخواه ثبت کنند.
- آموزش‌های اختصاصی نوشته‌شده برای پرس بالا سینه دمبل، پرس سینه دمبل و هالتر، و چند نسخه پشت‌بازو از جمله بالای سر دمبل و سیم‌کش، از توضیحات چند منبع معتبر بازنویسی شده‌اند. سایر رکوردهای کتابخانه که برچسب «آموزش نیازمند بررسی» دارند، عمداً راهنمای اختصاصی ساختگی دریافت نمی‌کنند.
